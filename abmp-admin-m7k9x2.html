Admin Access

Enter the admin passcode to continue. This page is not linked from the public website.

Note: this is a basic passcode gate for a static site. For full server-level security, the permanent admin will use Supabase sign-in, as ShopNest does.

WordPress jaisa, lekin us se easy: Pages, Blog, Appearance aur Settings — sab ek jagah, koi plugin ya database setup nahi. Save karte hi is browser me site update ho jati hai. Sab visitors ke liye permanent update ke liye Supabase wiring agla step hai, jo ShopNest me hai.

Staging admin, secret jaisa hi rakha hai: is file ka public site par koi link nahi hai, bilkul ShopNest ke secret admin paths ki tarah. Yahan se palette badalte hi homepage ka look badal jayega. Is prototype me change isi browser me save hota hai. Permanent version me yehi setting Supabase me jayegi, taake har visitor ko wahi palette dikhe.
